# mcsr-compare

---

## Features

- Pick 2 runners to compare stats
- Uses official MCSR APIs

---

## How to use

Before running make sure you have [Python 3](https://python.org).

Then run '''pip install requests''' to make sure that you have the requests module installed

Then run '''pip install prettytable''' to make sure that you have the prettytable module installed

To run, just open a terminal in the same folder as mcsr-compare.py and run python3 mcsr-compare.py
